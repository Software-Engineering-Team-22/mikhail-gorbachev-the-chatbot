# Chat with Mikhail Gorbachev

An interactive web-based chatbot application that allows users to engage in conversations with historical figures such as **Mikhail Gorbachev** — the last leader of the Soviet Union.

The platform offers an engaging and entertaining way to explore history through interactive conversations. Users can ask questions and discuss historical events while experiencing a simulated dialogue with some of history's most influential personalities.

By combining conversational AI with historical context, the application provides a fun and accessible approach to learning about the past.
